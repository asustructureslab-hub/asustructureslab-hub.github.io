Software

Software developed in the group. Each tool is built on formulations from the group papers.

Version 4.3 Windows Free

HRC Designer

Analysis and design software for members made with fiber reinforced concrete, hybrid reinforced concrete, UHPC, and textile reinforced concrete. Flexural test data gives the material properties, which then carry into section and member calculations in SI or US units.

HRC Designer hrcdesigner.com

Research code

UniversalHRC Engine

Generalized sectional analysis engine for arbitrary polygonal sections and batch back-calculation of experimental datasets.

Lead: Chidchanok Pleesudjai

Python package

parametric-uhpc

Parametric, closed-form inelastic simulation of UHPC and hybrid reinforced concrete flexural members with limit state analysis. Companion code to the Engineering Structures 2026 paper.

Lead: Devansh Patel

PyPI GitHub

Python code

FRP-FRC-Flexure

Closed-form flexural response of FRC and UHPC sections reinforced with steel or FRP bars, with an optional externally bonded FRP skin that engages after the section is already strained.

Lead: Devansh Patel
